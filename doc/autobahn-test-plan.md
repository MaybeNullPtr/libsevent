### ⚠️ 非预期/待定项（移至文档末尾供参考）

以下用例未通过标准的 PASS 判定，但属于已知预期内或规范未定义范围：

#### 1. 规范未定义行为（INFORMATIONAL，无害）

| 用例 | 内容 | 现象 |
|------|------|------|
| **7.1.6** | 256K 消息后紧接 CLOSE 再发 PING | 交互时序与预期不完全一致，行为无危害 |
| **7.13.1** | 发送 Close 码 5000 | RFC 未定义 5000+ 的行为，当前行为在规范容许范围内 |
| **7.13.2** | 发送 Close 码 65535 | 同上，65535 未定义 |

Autobahn 对这些用例标记为 `INFORMATIONAL`，不计入 PASS/FAIL。

#### 2. 已知 Bug（FAILED）

| 用例 | 内容 | 根因 | 影响 | 优先级 |
|------|------|------|------|--------|
| **7.5.1** | 发送非法 UTF-8 payload 的 Close 帧 | 库未对 Close payload 做 UTF-8 校验，未回复 1002/1007 错误码 | 仅影响极端场景（收到非法 UTF-8 Close 的对端行为未定义） | LOW |

## 推荐运行方案

```bash
# Autobahn 全量验证（~30s）
CASES='["1.*","2.*","3.*","4.*","5.*","7.*","9.*","10.*"]' bash tests/run_autobahn_docker.sh

# 内部快速验证（无需 Docker）
cmake -B build && cmake --build build && ctest
```

内化测试（`ctest`）覆盖：
- 精确填满 recv_cap + 0 字节终止帧
- 流式读取 + 0 字节终止帧
- 流式读取 + 最后分片 fin=1

> 测试报告保存于 `~/shared/autobahn_YYYYMMDD_HHMMSS/`，`~/shared/autobahn_latest` 始终指向最新报告。
