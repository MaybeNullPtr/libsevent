# Autobahn 合规测试项目

## 范围与预期

libsevent 是一个纯 C99 select() 事件循环库，WebSocket 客户端协议栈定位轻量嵌入式。以下测试分类基于此定位。

---

## 测试分组

### 1.* 基础帧 — 应全量测试 ✅

| 子组 | 内容 | 预期 |
|------|------|------|
| 1.1.1-1.1.8 | TEXT/BINARY 各种长度（0～65535） | PASS |
| 1.2.1-1.2.8 | UTF-8 编码文本 | PASS |

### 2.* 分片 — 应测试 ⚠️

| 子组 | 内容 | 预期 |
|------|------|------|
| 2.1-2.11 | 基本分片序列 | PASS |
| 2.12-2.15 | 大分片跨缓冲区边界 | 可能 FAIL（受 recv_buf_size 限制） |

### 3.* 分片+控制帧穿插 — 应测试 ⚠️

| 子组 | 内容 | 预期 |
|------|------|------|
| 3.1-3.7 | 分片间穿插 PING/PONG/CLOSE | PASS |
| 3.8+ | 非法穿插场景 | 部分 FAIL（取决于错误处理路径） |

### 4.* 控制帧 — 应测试 ⚠️

| 子组 | 内容 | 预期 |
|------|------|------|
| 4.1.1-4.1.5 | PING/PONG/CLOSE 基本 | PASS |
| 4.2.1-4.2.5 | 控制帧 payload >125 拒绝 | PASS（已实现校验） |
| 4.2.6+ | RSV 位、非法 opcode | PASS（已实现校验，on_error 触发） |

### 5.* 自动关闭行为 — 选测 ❓

| 子组 | 内容 | 预期 |
|------|------|------|
| 5.1-5.5 | 收到非法帧后关闭 | PASS（ws_fatal 触发） |
| 5.6-5.20 | Close 握手超时、对端不应答等 | **FAIL**（未实现关闭超时） |

### 6.* 编码 — 跳过 ❌

| 子组 | 内容 | 原因 |
|------|------|------|
| 6.1-6.22 | UTF-8 校验 | 库当前不做 UTF-8 校验，按设计选择 |
| 6.23+ | 无效 UTF-8 序列处理 | 同上 |

预期结果：全 FAIL，不影响功能。

### 7.* Close 码 — 应测试 ⚠️

| 子组 | 内容 | 预期 |
|------|------|------|
| 7.1-7.3 | 合法 Close 码 | PASS |
| 7.4-7.5 | 保留码（1004, 1012-1015 等） | PASS（已实现 ws_close_code_valid） |
| 7.6-7.13 | 非法码、空 payload 等 | 部分 PASS |

### 9.* Per-message Deflate — 跳过 ❌

| 原因 |
|------|
| 库不支持压缩扩展。如需支持需实现 permessage-deflate 扩展协商+zlib。 |

预期结果：全 FAIL / UNIMPLEMENTED。

### 12.* 扩展协商 — 跳过 ❌

| 原因 |
|------|
| 库当前不协商任何 WebSocket 扩展。 |

---

## 推荐运行方案

每次 CI / 提交前：

```bash
# 快速验证（~30s）
CASES='["1.*","2.*","3.*","4.*","5.*","7.*"]' bash tests/run_autobahn_docker.sh
```

可选扩展验证（含分片边界）：

```bash
CASES='["1.*","2.*","3.*","4.*","5.*","7.*","10.*"]' bash tests/run_autobahn_docker.sh
```

从不运行：

```bash
# 不支持的功能，跑也白跑
CASES='["6.*","9.*","12.*"]'  # ❌ 跳过
```
